# InstagramCrawling_Python  

#### 📢 인스타그램에서 검색을 통하여 나온 다양한 결과값을 크롤링한다.   
🖥️ 사용언어 : Python

<br>

1. instagram.py, instagram_p.py, instagramtest.py
   > 검색어 지정 후 인스타그램에서 나온 유저와 사진, 내용 결과값을 크롤링 해온다.

2. insta_형태소.py, insta_형태소트위터.py
   > 형태소를 구분한다.

3. insta_idfolder.py
   > 나온 결과값에 따라 인스타그램 유저들의 아이디로 폴더를 만든다.

4. insta_pic10infolder.py
   > 결과값 사진 10개를 하나의 폴더로 만들어 저장한다.
